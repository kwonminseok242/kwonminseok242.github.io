KOSCOM AI Agent Challenge 2025 · 대상

스테이블코인 리스크 관리 AI Agent

정해지지 않은 대회 주제를 스테이블코인 리스크로 직접 제안하고, 질문 하나로 근거 리포트와 증빙팩까지 남기는 AI 에이전트를 만들었습니다.

#AI_Agent#MCP#RAG#LocalBlockchain#MerkleTree#Compliance
결과KOSCOM AI Agent Challenge 2025 대상 (팀 단콤)
팀 / 내 역할4인 팀 · 주제와 기능 기획, 로컬 블록체인 환경 단독 구현, 백엔드·인프라·MCP·대시보드

문제

대회 공고의 주제는 MCP 서버 기반 차세대 금융 AI Agent였고, 무엇을 만들지는 팀이 정해야 했습니다. 한국은행 발표와 스테이블코인 도입 논의가 이어지고 있었지만, 국내에는 아직 명확한 법과 기준이 없었습니다.

판단: 주제 후보 세 가지

후보내용
A플랫폼 엔지니어링을 통한 개발자 경험(DevEx) 최적화
B제로 트러스트 기반 금융 보안 강화
C (선택)스테이블코인 거래 과정의 리스크를 AI로 탐지·관리

저는 C를 제안했습니다. 계속 논의되는 주요 이슈라고 판단했고, 코스콤이 이 분야 사업을 한다면 어떻게 할지를 기준으로 생각했습니다. 팀원들에게 스테이블코인과 과거 사건, 현재의 문제점을 직접 정리해 설명했고, 그 주제로 대회를 진행했습니다.

무엇을 만들었나

준비금·거래·규제준수를 한 흐름으로 묶었습니다. 사용자가 자연어로 질문하면 에이전트가 데이터를 조회·요약하고, 근거 리포트와 증빙팩을 남깁니다. 기준은 한국은행 자료를 참고하고, 정량 규격은 미국 지니어스 법안을 참조했습니다.

내가 한 일

  • 주제 제안과 기능 4개 기획, 기능별 분담 제안
  • 로컬 블록체인 환경 단독 구현 (실제 네트워크 대신 완성도를 높이기 위한 판단)
  • 백엔드, 인프라, MCP, 대시보드

팀이 한 일

  • Merkle tree 기반 무결성
  • 리포트 생성 + RAG + 슬랙 자동 알림
  • 온체인·오프체인 기록 관리

한계와 배운 점

  • 실제 블록체인 네트워크는 비용과 정책 문제로 쓰지 못하고 로컬 환경에서 구현했습니다.
  • 국내 법이 없어 지니어스 법안을 참조하거나 가정을 두고 진행했습니다. 한국 법 기준 설계는 아닙니다.
  • 금융 AI는 답만 내는 것으로는 부족하고, 근거와 증빙을 함께 남겨야 한다는 점을 설계로 옮겼습니다.
